# Design-Thinking-Project

🚀 First Time Setup (for teammates)
Open your terminal.

Run this to download the project:

bash
git clone https://github.com/tamoghnabiswas/Design-Thinking-Project.git
cd Design-Thinking-Project
Done ✅ — you now have the project folder on your laptop.

🔄 Daily Workflow (Every Time You Code)
👉 Think of this like a 3‑step routine:

Get the latest code before you start

bash
git pull origin main
(This makes sure you don’t overwrite someone else’s work.)

Save your changes locally

bash
git add .
git commit -m "Write what you changed"
Example:

bash
git commit -m "Fixed navbar color"
Upload your changes to GitHub

bash
git push origin main
⚡ Golden Rules
Pull before coding, push after coding.

Write clear commit messages (so we know what you did).

If Git shows a “merge conflict,” fix the file, then run:

bash
git add .
git commit -m "Solved merge conflict"
git push origin main
